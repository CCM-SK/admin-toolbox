# admin-toolbox
A simple, browser-based toolbox for IT administrators.
Admin Toolbox provides small utilities for working with common administration tasks directly in your browser.

Features
- log and text analysis
- certificate and encoding tools
- network and IP utilities
- hashing and conversion tools
- other useful admin utilities

Privacy
Everything is designed to run locally in your browser. No user data is intentionally uploaded to a server or sent to external services.
